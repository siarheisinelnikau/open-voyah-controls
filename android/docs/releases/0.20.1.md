# Local navigation cleanup 0.20.1

Android 0.20.1 pairs with the unchanged Windows installer 0.6.2. The signed kit uses the existing local certificates.

- Remove all activity aliases. Normal screens open through explicit MainActivity routes. The manifest declares only MainActivity, QuickVoiceActivity and SetupActivity.
- Route OEM voice-button launches directly to QuickVoiceActivity. External voice and installer entry points remain permission-protected. Controls can open its own protected voice window without holding that privileged permission.
- Remove obsolete component-based navigation and voice-action rewriting, the unused callback-based panel model, and the duplicate settings-route enumeration.
- Keep ordinary Back navigation available while voice commands load and use the same screen scaffold for loading and failure states.
- Preserve saved settings and native button fallback. Recreate shortcuts or reassign actions that still point to a removed screen component; those components no longer exist.

The graphite/blue interface, orange voice accents and unboxed icons are unchanged. See the [validation record](../../dist/VALIDATION_0.20.1.json) for exact Android 9/11 checks and artifact hashes. No vehicle qualification or full overseas account restoration is added.
