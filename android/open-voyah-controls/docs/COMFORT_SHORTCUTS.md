# Power Hold and car wash cards

Add **Power Hold** or **Car wash mode** to a desktop under **Desktop information cards**. Each card opens a confirmation for the corresponding existing factory command. Power Hold requests the factory confirmation. Car wash sends a request to the factory service and reports the reply it receives.

Controls checks the installed firmware's exact command review and the driver's **Allowed actions** setting before offering or dispatching the shortcut. On production builds the existing root transport also checks the approved software and package identities. The factory launcher checks live Parking gear and zero speed before dispatch. Canceling or leaving before the request is published revokes the pending confirmation. A request with an uncertain outcome is reported without automatic resend.

The default firmware catalog currently has no command-specific review rows for these cards. The cards explain the missing approval on such builds. The existing voice entry points and their permissions remain available according to their own admission policy. No device or firmware is qualified by the Android fixture.
