# Local validation build 0.19.0

This local kit pairs Android 0.19.0 with Windows installer 0.6.1. It has not been published. The changes below were checked with local fixtures, Android 9/11 emulators and Windows; no vehicle was used.

## Android

- Replaced shell expressions that crash Android 9's native `awk` in deployment validation, Telnet port checks and worker identity/exit checks. Malformed or uncertain evidence still refuses activation or cleanup.
- Tied activation to the installed app's channel key and identity, waited for verified unlocked storage, and recorded recovery before shutting down a revoked deployment.
- Required positive panel/window restoration and worker shutdown before reconnecting or updating. Explicit connection can renew an exhausted retry budget after verified cleanup; background retries remain bounded.
- Recorded the launcher and window session before injection. A replacement injector cannot claim it restored originals lost with the previous session. Recovery keeps uncertain sessions blocked, checks again after workers stop, and preserves a healthy window worker when its switch is enabled again.
- Replaced large PID comparisons with bounded decimal validation that behaves consistently in the Android 9 and 11 shells. Invalid journals remain available for recovery.
- Added explicit central Home and All apps assignments while retaining native behavior for unassigned buttons and failed launches. Fixed media retry and retired panel-handle cleanup.
- Preserved hardware-button capture ownership, classified delayed holds correctly, and expired stale actions. CAN capture and dispatch now recheck settings and time after target preflight, retaining owned release events without replaying physical gestures.
- Moved settings archive work off the UI thread and refreshed runtime configuration after restoration. Saved voice-window options together and improved microphone permission recovery.
- Added the Compose Updates screen, an optional quiet startup check, verified user-requested downloads, Android confirmation and durable installation recovery. Closing a screen at the IO handoff cannot leave an unattempted update permanently busy.
- Staged local APKs as bounded private snapshots, rejected self-updates from the generic installer, and handled Android 9 archive-signature collection. Persisted session creation intent before calling Android and verified asynchronous session removal before declaring cleanup complete.
- Replaced raw transport errors in connection status with localized recovery guidance while retaining meaningful compatibility and storage errors.

## Windows installer

- Preserved recovery across interrupted boot-entry upgrades and refreshed the explicitly selected device transport after preparation, including failures and cancellation.
- Honored cancellation before updater handoff and isolated partial downloads so interruption does not block a verified retry.
- Fixed the portable firmware evidence collector to use its bundled Java runtime and signature-verifier JAR. It checks the verifier before contacting ADB and preserves the selected SDK version.
- Verified the actual ADB version and transport-ID capability before packaging, then checked the copied executable and matching libraries again. Modern metadata cannot conceal an older executable. The local kit contains verified official Platform-Tools 37.0.1.
- Made PC recovery recognize pending launcher/window sessions even when normal worker markers are gone. It retires only an acknowledged original session or a positively changed target, and requires owner user 0 for window restoration.
- Added inspection of the actual init service and its configured root user before startup changes. A path mentioned in a comment or a service running as another user does not pass. Diagnostic collection includes available SELinux and process/file context metadata; cold-boot permission still needs device verification.

## Qualification still required

The production firmware and operation catalogs remain empty. Exact OEM boot context, ARM64 injection, CAN timing, physical effects, cold boot and sleep/wake require the intended head unit. Oversea A/B/C account writes remain unavailable without a complete verified backup and restoration contract. Numeric Driver 1/2/3 commands concern seat memory.

The kit uses local signing certificates. Windows system trust is unchanged. Private keys, OEM binaries and reference materials are excluded. The validation record accompanying the kit lists completed checks and their limits.
