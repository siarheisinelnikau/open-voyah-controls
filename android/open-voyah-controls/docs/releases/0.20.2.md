# Open Voyah Controls 0.20.2

This is the first public GitHub release of Open Voyah Controls and its Windows installer. Controls customizes the home screen, app grid, shortcuts and media controls on supported Voyah head units, with an English, Russian and Kazakh interface.

- Set up navigation, music and contact widgets on OVC Home. Save desktop layouts and assign shortcuts to buttons and the quick action bar.
- Use offline voice recognition with a bundled Russian model on ARM64. English, Kazakh and a backup Russian model can be downloaded in advance. The voice catalog and illustrated settings guides explain the available actions.
- Show Voyah Music and Voyah Radio on the factory cluster media card when the firmware has been reviewed for that feature. The factory card can be restored from settings.
- Installer 0.7.0 guides initial setup and same-signer updates over USB or Wi-Fi ADB. It also includes a device status page, boot-script backup and rollback, diagnostics, and a separate page for managing third-party apps.

### Downloads

- **OpenVoyahControls-v0.20.2.apk** is the signed Android app for ARM64 head units running Android 9 or 11. Deployment requires a compatible head unit and ADB root. Firmware-dependent operations require an exact firmware review.
- **OpenVoyahControlsInstaller-v0.7.0-portable-local-signed.zip** is the Windows x64 kit. Extract it and run the included executable with the `android-sdk` and `support` folders beside it. The kit includes the ADB tools, APK verifier and required ARM64 runtime.
- **OpenVoyahControlsInstaller-v0.7.0.exe** is the standalone Windows x64 executable for an existing portable kit or a PC with the required tools already set up.

The APK uses the same signing certificate as the earlier locally signed Controls builds. The installer uses the existing self-signed project certificate, so Windows may show an unknown publisher. SHA-256 checksums are provided for all three downloads.
