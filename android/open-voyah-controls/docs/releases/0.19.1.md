# Local recovery build 0.19.1

This local kit pairs Android 0.19.1 with Windows installer 0.6.2. It has not been published. No vehicle was used.

## Account-record recovery

- Validate every required snapshot member, ownership, file type, size and digest before changing the account record or any saved property value. A completion marker alone cannot authorize restoration.
- Publish the first verified snapshot as a synced unit and retain it across switches. Preserve original account bytes, ownership, permissions and SELinux context. Legacy or incomplete backups remain available and require separate review.
- Record interrupted transactions durably and refuse another guest switch until recovery is verified. A kernel lock prevents a surviving request from racing a later restoration after a transport timeout.
- Check the restored record, metadata and all four property values before and after account notifications. Missing property files cannot silently clear live values and report success.
- Describe the recovery action by its actual account-record scope. Seat-provider rows and other vehicle settings are outside this snapshot.

## Portable evidence and Windows diagnostics

- Collect the declared tracking provider owner, verified package metadata and declared account-related components without guessing its package name. Extra diagnostic packages cannot become firmware approval rows.
- Observe only bounded account-file metadata in the portable collector. No account record, token or account-file content hash is collected. Read operations have deadlines and remain bound to the selected transport.
- Replace the unrestricted property dump in ordinary diagnostics with explicit build, model, boot and security properties. Account, phone, token and serial properties are excluded from that file. Other diagnostic reports can contain OEM output and should still be reviewed before sharing.

## Remaining qualification

Overseas A/B/C selection still delegates to an unavailable OEM login implementation. The available interface does not establish all state it changes or a complete restoration contract. Overseas switching and restoration remain unavailable; the read-only probe is unchanged. See [account recovery boundaries](../ACCOUNT_RECOVERY.md).

The production firmware and operation catalogs remain empty. Exact OEM boot context, ARM64 injection and physical behavior still require the intended head unit. Local fixture tests establish the tested transaction and failure behavior, not complete OEM account recovery.

The kit uses the existing local signing certificates. Private keys and OEM reference materials are excluded. See the [validation record](../../dist/VALIDATION_0.19.1.json) for the checks actually completed and their limits.
