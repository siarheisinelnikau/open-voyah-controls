# Workspace and vehicle qualification

The starting Android code is Open Voyah Controls 0.20.2. The production firmware and operation catalogs retain their existing admission rules. The qualification for an optional action uses the installed fingerprint, SDK, primary ABI, product, relevant OEM signer and APK identity, and a reviewed operation row where the action requires one.

## Firmware evidence

- VOYAH FREE 318 with VOYAH OS 6.1.0 in the Guest profile has a prior user-facing observation. The installed Android fingerprint and its OEM admission data still need an authorized measurement. [Vehicle automation and H97D qualification](VEHICLE_AUTOMATION.md)
- A branch in the source for Free, Free Rest, BY, Norway, or Dreamer identifies candidate code. Consult the hardware-specific requirements before applying an operation approval to an installed unit. [Firmware coverage](FIRMWARE.md#firmware-coverage)
- A stock Android 13 x86_64 emulator can exercise UI, app-local persistence, and archive verification. It cannot establish Automotive property delivery, WindowManager behavior on the OEM build, or controller feedback.
